# GreenNest — Plant Care App

Responsive React/Vite plant care app: Login, Register, Home, Plant Catalog, Plant Details, Indoor Plants, Outdoor Plants, My Plants, Watering Schedule, Plant Care Guide, Profile.

## Run

```bash
npm install
npm run dev
```

## Publish to GitHub Pages

See **DEPLOY_GITHUB_PAGES.md**. The `.github/workflows/deploy.yml` workflow builds Vite and deploys the **dist** output on pushes to `main`.

The configured public URL is https://aruna0999.github.io/greennest/.

Note: login is a localStorage-only demonstration, not secure production authentication.
